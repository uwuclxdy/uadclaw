Why

Trust is the feature

A wrong removal rating reaches real phones through Canta, AppManager and android-debloat-list, so every answer has to earn its way upstream.

Deterministic first, model last

Facts come from the firmware bytes; the model writes only the description. Every value carries its provenance: rule, graph, llm, human.

A floor the model cannot lower

coreApp, priv-app, sharedUserId and friends pin a danger tier. A below-floor answer is rejected, never clamped.

Every answer faces an external check

A Brave search and a judge pass look for independent support. A citation the judge was never handed refuses the whole response.

Evidence you can re-ask

The LLM has no seed, so the bundle is the anchor: content-addressed, pinned, and the same hash means the same question.

A human approves every package

Every card shows the evidence, the proposal and the sources. You decide with the keyboard. The decision lands in an append-only log.

Nothing pushes itself

Approved entries append to a local branch with the disclosure upstream requires. A human pushes and opens the PR.

Pipeline

The full walk, firmware to branch

Every stage writes its own record. The paid ones wait for you to queue them.

StageWhat happens
acquireOne driver per OEM pulls the newest firmware for the models the operator names.
unpackDispatch on container-format magic numbers; ext4 via 7z, EROFS via fsck.erofs, Samsung .enc4 decrypted in the driver.
extract factsandroguard reads each APK manifest into typed facts, merged across devices by package name.
corpus graphTwo dependency edge classes only: overlay-to-target and required-library provider to consumer.
filterDrops what is already in uad_lists.json, auto-generated RROs, and emulator-only packages.
rule ladderThe removal floor from manifest and /etc signals; the model may raise it, never lower it.
llmThe LLM writes the description and proposes a removal; below-floor answers are rejected.
corroborateBrave search plus a judge pass; a fabricated citation refuses the whole response.
triageKeyboard-driven human gate, ranked by device count; decisions land in an append-only log.
branchApproved entries are appended to the operator's clone of upstream; the PR body carries the disclosure.

The split

Who does what

Six stages need no paid key

Acquire through rule ladder read firmware bytes, manifests and /etc signals. The deterministic half never touches a paid API.

Two stages spend, on your queue

The LLM and the corroboration judge run only when a human queues the classification job that pays for them.

Two stages are yours

Triage decides every package. The branch emission stops short of the push; a human opens the pull request.

Install

Docker Compose, three secrets, one dashboard

Postgres, the web dashboard and a worker, with credentials mounted as files.

Docker Composesh
git clone https://github.com/uwuclxdy/uadclaw
cd uadclaw
uv sync --frozen
cp .env.example .env
mkdir -p secrets
printf 'a long random postgres password' > secrets/postgres_password
printf 'a long random login password'    > secrets/auth_password
printf 'a long random session secret'    > secrets/session_secret
touch secrets/llm_deepseek_key secrets/brave_key
docker compose up -d --wait postgres
docker compose run --rm web alembic upgrade head
docker compose up -d

The dashboard comes up at http://localhost:8000, and login is the single password you set. Every settings key, with its default and what it gates, is on the Configuration wiki page.

FAQ

Common questions

What does uadclaw classify?
The preinstalled APKs of official OEM firmware, minus the partitions a named list waives as appless, for the Universal Android Debloater list.
Which phones does it support?
Pixel, Xiaomi, Nothing, Motorola, Samsung and Oppo/OnePlus/realme, one driver each. Unpacking dispatches on bytes, never on the OEM.
Does the model decide what gets removed?
No. The rule ladder sets a floor, the model proposes, and a human approves in triage. A below-floor answer is rejected, not clamped.
Does uadclaw push to upstream?
No. It commits a local branch and renders the PR body. A human pushes and opens the PR.
What does it cost to run?
LLM and Brave tokens for the two paid stages. The deterministic half needs no paid keys at all.
